## 만든 것

| 기능 | 내용 |
|---|---|
| 예산 (보고서 → 예산, 설정 → 예산) | 비용 계정별 **월 예산**. 금액을 넣으면 **자동 저장**(빈칸 = 예산 없음). 계정마다 사용 금액·남은 금액·사용률 막대와 상태(**✔ 여유 / ⚠ 주의 80% 이상 / ⛔ 초과**). 상위 계정(식비)에 예산을 넣으면 **하위 계정(외식·장보기) 지출 합산**. ‹ › 로 달 이동, **[지난달 예산 가져오기]** |
| 대시보드 예산 카드 | 이번 달 전체 예산 대비 지출 + 주의·초과 항목 |
| 반복 거래 (설정 → 반복 거래) | 이름, **매월/매주/매년**, 간격(2개월마다 등), 날짜(**말일** 선택 가능), 시작일·종료일, 거래 내용(간편 입력 또는 분개). 다음 예정일 미리 보기. 켜기/끄기, 수정, 삭제 |
| 등록 대기 | 예정일이 된 반복 거래가 **대시보드·입력 화면 맨 위**에 나타남 → **[등록]** / **[금액 고쳐 등록]**(이번 회차만) / **[건너뛰기]** / **[모두 등록]**. 등록하면 다음 예정일로 자동으로 넘어감. 두 기기에서 같은 회차를 동시에 등록해도 **한 번만** 들어감(DB 검사) |
| 즐겨찾기 | 간편 입력에서 계정을 고른 뒤 **[☆ 이 입력을 즐겨찾기로 저장]** → 입력 화면 맨 위 **★ 줄**에 나타남. 누르면 종류·계정·메모(·금액)가 채워짐. 금액을 비워 저장하면 금액 칸으로 바로 커서. 설정 → 즐겨찾기에서 이름·순서 변경, 삭제 |

- 반복 거래 등록·예산 저장·즐겨찾기 저장은 인터넷 연결이 필요합니다. 즐겨찾기 **사용**은 오프라인에서도 됩니다(기기에 저장).
- 자동 테스트: `tests.html` **51건** (예산 계산·상태, 반복 예정일·규칙 문장·등록 대기·틀→분개 추가). DB 테스트: 다음 예정일 계산이 화면 계산과 같은지, 종료일 지나면 자동 꺼짐, 즐겨찾기·반복 거래 RLS 추가.

## 5단계 테스트 시나리오

### A. 예산 (복식부기와 연결)
1. 보고서 → 예산 → **식비** 칸에 `100000` → 잠시 뒤 "저장됨".
2. 간편 입력으로 **지출 85,000 · 식비 · 현금** 저장 → 예산 화면: 식비 사용 85,000 · **15,000원 남음 · ⚠ 주의**(85%).
3. 지출 20,000 · 식비 하나 더 → **5,000원 초과 · ⛔ 초과**, 대시보드 예산 카드에도 식비 ⛔ 초과 표시.
4. (하위 계정 합산) 설정 → 계정과목 → 식비 아래 **외식** 추가 → 지출 10,000 · 외식 → 예산 화면 **식비 사용액에 외식 10,000이 더해짐**.
5. 그 전표를 휴지통으로 옮기면 예산 사용액에서도 빠지는지 확인.
6. 다음 달로 ‹ › 이동 → [지난달 예산 가져오기] → 식비 100,000이 복사됨.

### B. 반복 거래
1. 설정 → 반복 거래 → [+ 반복 거래 추가]
   - 이름 **통신비**, 매월, 날짜 **오늘 날짜의 일**(예: 오늘이 7일이면 7일), 시작일 오늘
   - 거래 내용: 지출 **55,000** · 통신 · 주거래 통장 → [반복 거래 저장]
   - "다음 예정일 (오늘) · 저장하면 바로 등록 대기에 나타납니다"
2. 대시보드 맨 위 **반복 거래 등록 대기 1건 — 통신비 55,000원** → [등록]
   - 거래 목록에 통신비 55,000 전표가 생김 (상세 화면 종류: 지출)
   - 반복 거래 목록의 다음 예정일이 **다음 달 같은 날**로 바뀜
   - 대시보드 순자산 **55,000원 감소**
3. (금액 고쳐 등록) 반복 거래 하나를 시작일 = 오늘, 날짜 = 오늘로 더 만들고 → 등록 대기에서 **[금액 고쳐 등록]** → 금액 61,000 → [이번 회차 등록] → 전표는 61,000, 반복 거래의 평소 금액은 그대로.
4. (건너뛰기) 등록 대기에서 [건너뛰기] → 전표 없이 다음 예정일만 넘어감.
5. (말일) 날짜 **말일**로 만들면 규칙이 "매월 말일", 2월에는 28(29)일로 계산되는지 다음 예정일로 확인.
6. (두 기기) 같은 반복 거래를 PC와 휴대폰에 등록 대기로 띄워 둔 채 한쪽에서 [등록] → 다른 쪽에서 [등록]하면 "이미 등록했거나 건너뛴 반복 거래입니다" 안내, 전표는 1건만.

### C. 즐겨찾기
1. 입력 → 간편 입력 → 지출 · **식비** · **주 사용 카드** 고르기(금액 비움) → [☆ 이 입력을 즐겨찾기로 저장] → 이름 "점심 카드" → 저장.
2. 입력 화면 맨 위 **★ 즐겨찾기** 줄에 "점심 카드".
3. 다른 종류(수입 등)로 바꾼 뒤 "점심 카드" 누르기 → 지출 · 식비 · 주 사용 카드가 채워지고 **금액 칸에 커서** → 금액 입력 → [저장]. (휴대폰: [+ 입력] → 즐겨찾기 → 금액 → [저장])
4. 설정 → 즐겨찾기 → 이름 바꾸기, ↑↓ 순서, 삭제.
