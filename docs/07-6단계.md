# 6단계 — 백업·복원 · CSV · 은행·카드 내역 가져오기 · 가족 초대

## ⚠️ 먼저: DB 업데이트 (한 번만)

1. Supabase **SQL Editor** → **New query**
2. [`sql/migrations/004_restore_members.sql`](../sql/migrations/004_restore_members.sql) 전체를 붙여넣고 **Run** → **Success**
3. (권장) [`sql/tests.sql`](../sql/tests.sql) 다시 실행 → **✅ 모든 테스트 통과** (백업→복원 비교, 구성원 정보 점검 추가)

> 실행하지 않으면 앱을 열 때 "DB 업데이트가 필요합니다 (현재 3 → 필요 4)" 안내가 뜨고, 복원과 구성원 목록이 동작하지 않습니다.

## 만든 것

| 기능 | 위치 | 내용 |
|---|---|---|
| JSON 백업 | 설정 → 데이터 관리 | 장부 전체(계정과목, 전표+휴지통, 예산, 반복 거래, 즐겨찾기)를 파일 하나로 내려받기 |
| 복원 | 설정 → 데이터 관리 | 백업 파일 선택 → 내용 확인(건수, 차대 검사) → **새 장부로 복원**. 지금 장부는 그대로. 한 번에 처리되어 실패하면 아무것도 만들어지지 않음 |
| CSV 내보내기 | 거래 목록·시산표·재무상태표·손익계산서·원장·예산의 **[CSV]**, 데이터 관리의 전체 분개장 | 엑셀에서 한글이 깨지지 않게 저장(UTF-8 BOM). 거래 목록은 지금 걸린 필터 그대로 |
| 은행·카드 내역 가져오기 | 설정 → 데이터 관리 → 은행·카드 내역 가져오기 | **CSV(UTF-8·EUC-KR 자동)·엑셀(xlsx·xls)**. 머리글 줄·날짜·내용·금액 열 **자동 추측**(통장 출금/입금 열, 카드 금액 열 모두). 미리보기에서 **줄마다 항목 고르기**, 같은 가맹점은 **예전에 고른 항목 자동 추천**, 장부에 이미 있는 것 같은 줄(같은 날·같은 금액·같은 계좌)은 **기본으로 뺌**, 합계 줄 등은 건너뜀 |
| 장부·가족 | 설정 → 장부·가족 | 장부 이름 변경, **구성원 목록(이메일)**, 소유자 지정·내보내기·나가기, **초대 코드 만들기**(7일·1회, 이메일 지정 가능, 안내문 복사·공유), **초대 코드로 합류**, **새 장부 만들기**, **장부 삭제**(이름을 직접 입력해 확인) |

### 가져온 내역이 만드는 분개

| 나간 돈(출금·카드 사용) | 고른 항목 (식비 등 비용 / 카드대금이면 그 카드 / 이체면 받는 계좌) | 이 파일의 계좌·카드 |
| 들어온 돈(입금·환불) | 이 파일의 계좌·카드 | 고른 항목 (급여 등 수익 / 이체면 보낸 계좌 / 환불이면 그 비용) |

## 6단계 테스트 시나리오

### A. 백업 → 복원 (복식부기 검증)
1. 대시보드 **순자산**과 보고서 → 시산표의 **차변 합계**를 적어 둡니다.
2. 설정 → 데이터 관리 → **[JSON 백업 내려받기]** → "계정 N개, 전표 N건" 안내, 파일이 내려받아짐.
3. 같은 화면 **복원**에서 방금 파일 선택 → 건수 요약 확인 → **[새 장부로 복원]**.
4. 화면 위쪽 장부 이름이 "○○ (복원 날짜)"로 바뀜 → 대시보드 순자산, 시산표 차변 합계가 **1번과 똑같은지** 확인. 반복 거래·즐겨찾기·예산도 들어 있는지 확인.
5. 위쪽에서 원래 장부로 바꿔 보면 그대로 있음 → 복원한 장부는 설정 → 장부·가족 → **[이 장부 삭제]**(장부 이름 입력)로 정리.

### B. CSV 내보내기
1. 거래 목록(이번 달) → **[CSV]** → 엑셀로 열어 한글이 깨지지 않고, 전표마다 차변·대변 줄이 나오는지, **차변 열 합계 = 대변 열 합계**인지 확인.
2. 시산표 **[CSV]** → 마지막 "합계" 줄의 차변 합계 = 대변 합계.

### C. 은행·카드 내역 가져오기
1. 인터넷뱅킹에서 최근 거래내역을 **엑셀 또는 CSV**로 내려받습니다(카드사 이용내역도 가능).
2. 설정 → 데이터 관리 → 은행·카드 내역 가져오기 → 파일 선택.
3. "2. 열 지정"에서 자동 추측이 맞는지 확인하고 **이 파일의 계좌·카드**를 고름(통장 파일이면 주거래 통장, 카드 파일이면 그 카드).
4. 미리보기: 이미 앱에 입력한 거래(같은 날·같은 금액)는 **"이미 있는 거래일 수 있음"**으로 빠져 있음. 나머지 줄의 항목을 고름(카드대금 출금 줄은 그 카드, 다른 내 통장으로 보낸 돈은 그 통장).
5. **[가져오기]** → "N건을 장부에 넣었습니다" → 거래 목록·대시보드에 반영, 시산표 **일치 ✔**.
6. 같은 파일을 다시 가져오면 방금 넣은 줄이 모두 **중복으로 빠지고**, 같은 가맹점은 지난번 항목이 **자동 추천**됨.
7. (통장 파일) 가져온 뒤 계정별 원장에서 그 통장의 **기간 말 잔액이 은행 앱의 잔액과 같은지** 확인 — 개시 잔액을 맞게 넣었다면 일치해야 합니다.

### D. 가족 초대
1. (소유자) 설정 → 장부·가족 → [초대 코드 만들기] → 코드 10자리, [안내문 복사].
2. 가족(다른 계정)이 가입·로그인 → 설정 → 장부·가족 → **초대 코드로 합류**에 입력 → 장부가 추가되고 그 장부로 바뀜.
3. 두 사람이 각각 전표를 입력 → 서로의 거래 목록·대시보드에 보임. 전표 상세에 작성자 "나 / 다른 구성원" 표시.
4. 같은 코드를 다시 쓰면 "초대 코드가 없거나 만료되었습니다".
5. (소유자) 구성원 목록에서 [내보내기] → 그 사람 화면에서 그 장부가 사라짐(입력한 전표는 남음).
