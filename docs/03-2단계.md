# 2단계 — 간편 입력 · 개시 잔액 마법사 · 계정 관리 · PWA·오프라인

## 만든 것

| 영역 | 내용 |
|---|---|
| 간편 입력 (기본) | **지출 / 수입 / 이체 / 카드대금 / 대출 상환**. 금액을 넣고 칩을 한 번 눌러 고르면 자동 분개. 하단에 "이렇게 기록됩니다: 차변 ○○ / 대변 ○○" 미리보기 |
| 지출 3터치 | ① [+ 입력] → (금액 칸에 커서가 바로 가 숫자 키패드가 뜸) 금액 입력 → ② 항목 칩(식비 등) → ③ [저장]. 결제수단은 **최근에 쓴 계정이 미리 선택**됨 |
| 최근 사용 순서 | 모든 칩은 최근에 쓴 계정이 앞에. 자주 안 쓰는 항목은 [더보기] |
| 고급 입력 | 1단계와 같음. [간편 입력 / 고급 입력 (분개)] 전환, 마지막 선택을 기억 |
| 개시 잔액 마법사 | 새 장부를 처음 열면 자동으로 뜸(한 번). 가진 돈·갚을 돈 입력 → 기초 순자산 자동 계산 → 개시 전표 1건. **통장·카드·대출을 화면에서 바로 추가** 가능. 설정·대시보드에서도 열 수 있음 |
| 계정과목 관리 | 설정 → 계정과목: 추가(최상위·하위), 이름 변경, 숨기기/다시 보이기, 삭제(거래 없는 계정만) |
| PWA | `manifest.json`, 아이콘, 서비스 워커(`sw.js`). 홈 화면에 추가하면 전체 화면 앱으로 실행 |
| 오프라인 | 앱 화면은 인터넷 없이도 열림. 오프라인 중 저장한 전표는 **기기(IndexedDB)에 임시 보관** → 연결되면 자동 저장. 상단에 **"저장 대기 N"** 표시, 입력 화면에 대기 목록 |
| 저장 실패 처리 | 서버가 거부한 대기 전표는 "저장 실패 N"으로 표시, 이유와 함께 [다시 시도]·[지우기] |

### 새 파일
```
js/core/simple.js            간편 입력·개시 잔액 → 분개 변환, 최근 사용 정렬 (화면 코드 없음)
js/data/outbox.js            저장 대기열 (IndexedDB)
js/data/sync.js              대기열 → 서버 전송, 재시도
js/ui/chips.js               선택 칩
js/ui/screens/entry-simple.js / entry-advanced.js / opening.js
manifest.json, sw.js, icons/ (tools/make-icons.mjs로 생성)
```
- DB(schema.sql)는 바뀌지 않았습니다. 다시 실행할 필요 없습니다.
- 자동 테스트: `tests.html` **29건** (간편 입력 5종·개시 잔액·최근 사용 순서 추가)

### 간편 입력이 만드는 분개
| 종류 | 차변 | 대변 |
|---|---|---|
| 지출 | 비용 (예: 식비) | 현금·통장 또는 카드(부채 증가) |
| 수입 | 입금 계좌 | 수익 (예: 급여) |
| 이체 | 받는 계좌 | 보내는 계좌 |
| 카드대금 | 카드 (부채 감소) | 통장 |
| 대출 상환 | 대출 원금(부채 감소) + 대출이자(비용) | 통장 (합계) |

## 2단계 테스트 시나리오

> 1단계에서 넣은 테스트 전표가 있으면 결과 숫자가 달라집니다. **새 장부로 깔끔하게 확인**하려면 다른 이메일로 새 계정을 만들어 진행하세요(가입하면 개인 장부가 새로 생깁니다).

### A. 개시 잔액 마법사
1. 새 계정으로 로그인 → **개시 잔액 설정** 화면이 자동으로 뜹니다.
2. [+ 통장 추가] → "월급통장" 추가 → 목록에 "보통예금 > 월급통장"이 생기는지 확인.
3. 현금 100,000 / 주거래 통장 2,000,000 / 주 사용 카드 300,000 입력.
4. 결과: 자산 2,100,000 · 부채 300,000 · **기초 순자산 1,800,000**, 미리보기 "차변 현금 100,000, 주거래 통장 2,000,000 / 대변 주 사용 카드 300,000, 기초 순자산 1,800,000" → [개시 잔액 저장].
5. 대시보드: 순자산 **1,800,000**, 검증 ✔ 3개.

### B. 간편 입력 (각 저장 뒤 대시보드 확인)
| # | 입력 | 미리보기 | 대시보드 순자산 |
|---|---|---|---|
| 1 | **지출** 30,000 · 식비 · 주 사용 카드 | 차변 식비 30,000 / 대변 주 사용 카드 30,000 | **1,770,000** (−3만) |
| 2 | **카드대금** 330,000 · 주 사용 카드 · 주거래 통장 | 차변 주 사용 카드 330,000 / 대변 주거래 통장 330,000 | **1,770,000** (변화 없음), 부채 0 |
| 3 | **수입** 3,000,000 · 급여 · 주거래 통장 | 차변 주거래 통장 / 대변 급여 | **4,770,000** |
| 4 | **이체** 500,000 · 주거래 통장 → 적금 | 차변 적금 / 대변 주거래 통장 | **4,770,000** (변화 없음) |
| 5 | **대출 상환** — 먼저 개시 잔액이나 고급 입력으로 대출 잔액을 넣어 둔 경우: 원금 500,000 · 이자 50,000 | 차변 대출 500,000, 대출이자 50,000 / 대변 주거래 통장 550,000 | **−5만**(이자만 감소, 원금 상환은 순자산 불변) |

- 지출을 두 번째로 입력할 때 **결제수단이 방금 쓴 카드로 미리 선택**되어 있는지 확인.
- 휴대폰에서: [+ 입력] → 금액 → 식비 → [저장] = **3터치**로 저장되는지 확인.

### C. 오프라인 (휴대폰 권장)
1. 앱을 한 번 연 뒤 **홈 화면에 추가** (설정 화면에 방법 안내).
2. **비행기 모드**를 켜고 홈 화면 아이콘으로 실행 → 앱이 열리고 상단에 **오프라인** 표시.
3. 지출 5,000 · 교통 · 현금 저장 → "기기에 임시 저장했습니다" 안내, 상단 **저장 대기 1**, 입력 화면에 대기 목록.
4. 비행기 모드 끄기 → 잠시 뒤(또는 [지금 보내기]) "임시 저장해 둔 전표 1건을 서버에 저장했습니다" → 대기 표시 사라짐 → 최근 전표·대시보드에 반영(순자산 −5,000).
5. 같은 전표가 **두 번 저장되지 않았는지** 최근 전표에서 확인.

### D. 계정과목 관리
1. 설정 → 계정과목 → **식비** 누르기 → [+ 하위 계정] → "외식" 추가.
2. 간편 입력 → 지출의 항목 칩에 **외식**이 생기고, **식비는 사라짐**(하위가 생긴 상위 계정에는 직접 기록 불가).
3. "외식" → [숨기기] → 입력 화면에서 사라지는지 확인 → [다시 보이기].
4. 거래가 있는 "현금" → [삭제] → "거래가 있는 계정은 삭제할 수 없습니다. 숨김을 사용하세요." 안내.
5. 기초 순자산은 [삭제] 버튼이 없습니다(기본 계정).
