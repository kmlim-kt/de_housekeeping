# 3단계 — 거래 목록 · 전표 수정·삭제·휴지통 · 계정별 원장 · 시산표

## ⚠️ 먼저: DB 업데이트 (한 번만)

이번 단계부터 거래 검색 함수가 DB에 필요합니다.

1. Supabase 대시보드 → **SQL Editor** → **New query**
2. [`sql/migrations/002_search_transactions.sql`](../sql/migrations/002_search_transactions.sql) 내용을 전부 붙여넣고 **Run**
3. **Success** 가 나오면 완료입니다. (여러 번 실행해도 안전합니다)
4. (권장) [`sql/tests.sql`](../sql/tests.sql)을 다시 실행해 **✅ 모든 테스트 통과** 확인 — 검색·휴지통·RLS 점검이 추가되었습니다.

> 업데이트를 하지 않으면 앱을 열 때 "DB 업데이트가 필요합니다" 안내가 뜨고, 거래 목록이 열리지 않습니다.
> 처음 설치하는 경우에는 `schema.sql`에 이미 포함되어 있어 따로 실행하지 않아도 됩니다.

## 만든 것

| 화면 | 내용 |
|---|---|
| 거래 목록 (분개장) | 날짜별 묶음 + 일별 합계. 필터: **기간**(이번 달·지난 달·올해·전체·직접), **계정**(상위 계정이면 하위 포함), **검색어**(메모·계정 이름), **금액 범위**. 50건씩 [더 보기] |
| 휴지통 | 거래 목록의 [휴지통] 탭. **복원**, **영구 삭제**, **휴지통 비우기** |
| 전표 상세 | 분개 라인, 작성자·시각, **변경 이력**(작성·수정·삭제·복원, 수정이면 바뀌기 전/후 분개) |
| 전표 수정 | 간편 입력으로 만든 전표는 **간편 입력 화면 그대로**(값이 채워진 채로) 수정, 그 밖에는 고급 입력. 다른 기기에서 먼저 고쳤으면 **거부하고 알림**(덮어쓰기 방지) |
| 삭제 | [삭제] → 휴지통으로 이동, 알림의 **[되돌리기]**로 바로 취소 가능. 휴지통 전표는 잔액·보고서에서 빠짐 |
| 계정별 원장 | 계정 선택(상위면 하위 합산) + 기간 → **기간 전 잔액(이월) / 차변·대변 합계 / 기간 말 잔액**, 거래마다 상대 계정과 누적 잔액. 누르면 전표 상세 |

## 3단계 테스트 시나리오

1·2단계에서 입력한 장부를 그대로 써도 됩니다. 아래는 2단계 시나리오(개시 잔액 → 카드 식비 3만 → 카드대금 33만 → 급여 300만 → 적금 이체 50만)를 넣은 장부 기준입니다.

### A. 시산표 (보고서 → 시산표)
1. 맨 위에 **차변·대변 일치 ✔ 정상**, 합계(차변/대변)가 같은 숫자인지 확인.
2. 잔액(차변/대변)도 같은 숫자인지 확인.
3. 휴대폰: 보통예금 ▶ 누르면 "주거래 통장"(과 추가한 통장)이 펼쳐짐. PC: 표로 보임.
4. 기준일을 **카드대금 결제 전날**로 바꾸면 신용카드가 **대변 잔액 330,000**으로 바뀌는지 확인.

### B. 계정별 원장 (보고서 → 계정별 원장)
1. 계정 **신용카드 (하위 포함)**, 기간 **전체** → 누적 잔액이 **300,000 → 330,000 → 0** 순서.
2. 기간 전 잔액(이월) + 차변·대변 증감 = 기간 말 잔액인지 확인.
3. 줄을 누르면 해당 전표 상세로 이동.

### C. 거래 목록·검색
1. 기간 **이번 달** → 입력한 전표가 날짜별로 보임.
2. 계정 필터 **보통예금 (하위 포함)** → 통장이 들어간 전표만.
3. 검색어 **급여** → 급여 전표만. **+ 금액 범위** 최소 1,000,000 → 100만 원 이상만.
4. [필터 초기화].

### D. 수정 (복식부기 확인)
1. "점심"(식비 30,000) 전표 → [수정] → **간편 입력 화면에 값이 채워져** 열림(종류는 잠김).
2. 금액을 **35,000**으로 → [수정 저장].
3. 상세 화면 **변경 이력**에 "수정 — 분개: 차변 식비 30,000 … → 차변 식비 35,000 …".
4. 대시보드 순자산이 **5,000원 더 줄었는지**, 시산표가 여전히 **일치 ✔**인지 확인.
5. (충돌 확인, 선택) 같은 전표를 PC와 휴대폰에서 동시에 수정 화면으로 연 뒤, 한쪽에서 저장 → 다른 쪽에서 저장하면 **"다른 기기에서 먼저 수정한 전표입니다"** 안내가 뜨고 저장되지 않음.

### E. 삭제·휴지통·복원
1. "점심" 상세 → [삭제] → 거래 목록으로 이동, 알림에 **[되돌리기]** → 누르면 다시 목록에 나타남.
2. 다시 [삭제] → 대시보드 순자산이 **35,000원 늘어남**(지출이 빠졌으므로), 시산표 **일치 ✔**.
3. 거래 목록 → [휴지통] → "점심" → [복원] → 순자산 원래대로.
4. 다시 삭제 후 휴지통에서 [영구 삭제] → 휴지통에서 사라짐. (테스트 전표 정리에 사용하세요)
