### 용어 정리 (가계부 기준)
| 용어 | 뜻 |
|---|---|
| 순자산 | 자산 − 부채 (내 몫의 재산) |
| 기초 순자산 | 장부를 시작할 때의 순자산 (개시 잔액에서 계산) |
| 누적 손익 | 장부 시작 후 지금까지 수익 − 비용. 순자산 = 기초 순자산 + 누적 손익 |
| 당기순이익 | 선택한 기간의 수익 − 비용 (= 그 기간에 모은 돈) |
| 저축률 | 당기순이익 ÷ 수익 |

## 4단계 테스트 시나리오

지금까지 쓴 장부 그대로 확인하면 됩니다. 아래는 **2단계 시나리오만 넣은 새 장부** 기준 숫자입니다
(개시: 현금 10만·통장 200만·카드 30만 → 카드 식비 3만 → 카드대금 33만 → 급여 300만 → 적금 이체 50만, 모두 이번 달).

### A. 재무상태표 (보고서 → 재무상태표, 기준일 오늘)
| 항목 | 기대값 |
|---|---|
| 자산 | 현금 100,000 · 보통예금(주거래 통장) **4,170,000** · 적금 500,000 → **합계 4,770,000** |
| 부채 | 카드대금을 모두 냈으므로 **0** |
| 순자산 | 기초 순자산 1,800,000 + 누적 손익 2,970,000 → **4,770,000** |
| 표시 | **✔ 자산 = 부채 + 순자산** (4,770,000 = 0 + 4,770,000) |

> 주거래 통장 계산: 개시 200만 − 카드대금 33만 + 급여 300만 − 적금 이체 50만 = **417만**
> 누적 손익: 급여 300만 − 식비 3만 = **297만**

### B. 손익계산서 (월별, 이번 달)
| 항목 | 기대값 |
|---|---|
| 수익 | 급여 **3,000,000** |
| 비용 | 식비 **30,000** |
| 당기순이익 | **2,970,000** (= 재무상태표의 누적 손익과 같음, 장부를 이번 달에 시작했으므로) |
| 저축률 | **99%** |
| 이전 기간(‹) | 지난달은 거래가 없으므로 0, "이 기간 수익 없음" |

### C. 대시보드
1. 이번 달 수입 **3,000,000**, 지출 **30,000**, 저축 **2,970,000**, 저축률 **99%**.
2. 순자산 **4,770,000원**, 전월 말 대비 **▲ +4,770,000원**(지난달 말에는 장부가 없었으므로 0에서 시작).
3. 순자산 그래프: 지난 11개월은 0, 이번 달에 477만으로 올라감. 그래프 위에 손가락을 대면 그 달 값이 나옴.
4. 수입·지출 막대: 이번 달만 파랑(수입) 300만, 주황(지출) 3만.
5. [표로 보기]를 누르면 그래프와 같은 숫자가 표로 보임.
6. 지출 상위: 식비 30,000 · 100%. 누르면 식비 원장으로 이동.

### D. 교차 확인 (복식부기)
- 손익계산서 **당기순이익** = 대시보드 **저축** (같은 달)
- 재무상태표 **순자산 합계** = 대시보드 **순자산** = 시산표 기준 자산 − 부채
- 전표 하나를 휴지통으로 옮기면 세 화면 숫자가 **함께** 바뀌고, 복원하면 원래대로.
